# 6CS056 — Training Institute Management System

Laravel web application developed progressively across module workshops using Git branching (`main`, `Workshop1`, `Workshop2`).

## Project Structure
- `6CS056-Workshop/` — Active Laravel application (Models, Migrations, Blade UI, CRUD routes)
- `completed_workshops/` — Local frozen snapshots of completed workshop milestones (`Workshop1`, `Workshop2`) stored outside `.git`

## Branches & Milestones
- **`Workshop1`**: Completed Student CRUD and Course CRUD with custom responsive Blade UI (`WorkshopDB`)
- **`Workshop2`**: Active development branch for upcoming workshop features
